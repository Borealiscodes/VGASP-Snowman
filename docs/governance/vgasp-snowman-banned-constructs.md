🧩 1. Overview
Banned constructs are operations that violate:

- invariant surfaces  
- curvature thresholds  
- holonomy locks  
- dissipation gates  
- governance constraints  
- deterministic operator ordering

They are globally illegal across all Snowman systems.

---

🚫 2. Banned Construct Categories

❌ 2.1. Invariant Violations
These break identity, symmetry, or canonical surfaces.

Operators must never:

- create decorations before invariant surfaces exist  
- alter identity tensors \( I_{ij} \)  
- break symmetry constraints  
- generate non‑canonical surfaces

Invariant violations destabilize the entire Snowman geometry.

---

❌ 2.2. Curvature Violations
These break geometric stability.

Operators must never:

- stack on negative curvature  
- roll after curvature is locked  
- create curvature discontinuities  
- exceed curvature thresholds \( K_{crit} \)

Curvature violations cause collapse, drift, or catastrophic instability.

---

❌ 2.3. Holonomy Violations
These break orientation and path‑dependent geometry.

Operators must never:

- decorate before holonomy is fixed  
- roll after holonomy is locked  
- create holonomy loops that violate invariants  
- generate non‑contractible holonomy paths

Holonomy violations cause orientation drift and non‑deterministic geometry.

---

❌ 2.4. Dissipation Violations
These break thermal and deformation constraints.

Operators must never:

- decorate melting surfaces  
- stack during active dissipation  
- roll when dissipation exceeds \( D_{crit} \)  
- create dissipation hotspots

Dissipation violations cause melting, deformation, or structural collapse.

---

❌ 2.5. Ordering Violations
These break deterministic roll → stack → decorate ordering.

Operators must never:

- decorate before stacking  
- stack before rolling  
- roll after stacking  
- roll after decorating  
- stack after decorating

Ordering violations break the entire governance architecture.

---

❌ 2.6. JSON Logic Violations
These break system‑agnostic governance logic.

Operators must never:

- emit JSON operators out of order  
- create illegal JSON surfaces  
- violate JSON invariant fields  
- generate non‑canonical JSON operator sequences

JSON violations break cross‑language determinism.
