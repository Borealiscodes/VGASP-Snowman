🧭 2. JSON Governance Fields

🟦 2.1. invariant
Represents identity + symmetry constraints.

Must encode:

- identity surfaces  
- symmetry planes  
- invariant boundaries  
- allowed decoration zones

Must never encode:

- illegal identity changes  
- symmetry violations  
- pre‑structure decoration

---

🔵 2.2. curvature
Represents geometric stability.

Must encode:

- curvature thresholds  
- curvature‑invariant surfaces  
- stack alignment geometry

Must never encode:

- negative curvature stacks  
- curvature discontinuities  
- unstable decoration zones

---

🌀 2.3. holonomy
Represents orientation + path‑dependent geometry.

Must encode:

- holonomy locks  
- orientation alignment  
- allowed decoration orientation

Must never encode:

- decoration before holonomy lock  
- roll after holonomy lock  
- non‑contractible holonomy loops

---

🔥 2.4. dissipation
Represents melting + deformation.

Must encode:

- thermal thresholds  
- deformation gradients  
- dissipation gates

Must never encode:

- decoration on melting surfaces  
- stack during dissipation  
- roll above \( D_{crit} \)
