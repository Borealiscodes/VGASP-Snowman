🧩 1. Overview
JSON operators define the allowed machine‑level actions:

- roll  
- stack  
- decorate

Each operator:

- encodes tensor constraints  
- enforces invariant surfaces  
- respects dissipation rules  
- follows deterministic ordering  
- produces machine‑safe geometry

---

🌀 2. Operator: roll

Purpose
Create curvature, mass distribution, and orientation.

JSON Form
`json
{
  "op": "roll",
  "invariant": { ... },
  "curvature": { ... },
  "holonomy": { ... },
  "dissipation": { ... }
}
`

Must Enforce
- curvature thresholds  
- holonomy trajectory  
- dissipation minimization  
- identity preservation

Must Never
- roll after stack  
- roll after decorate  
- roll across invariant surfaces  
- roll above \( D_{crit} \)

---

🏗️ 3. Operator: stack

Purpose
Align centers, stabilize curvature, finalize structure.

JSON Form
`json
{
  "op": "stack",
  "invariant": { ... },
  "curvature": { ... }
}
`

Must Enforce
- curvature‑invariant surfaces  
- identity boundaries

Must Never

- stack on negative curvature  
- stack during dissipation

🎨 4. Operator: decorate

}
`

---

🔢 5. Operator Ordering (Machine‑Level)

JSON operator sequences must follow:

`
roll → stack → decorate
`

JSON logic must reject:

- decorate → roll  
- stack → roll  
- decorate → stack  
- roll → decorate → stack  
- any non‑canonical permutation

Ordering violations are fatal governance errors.
